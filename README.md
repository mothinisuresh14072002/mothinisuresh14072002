I focus on building AI as a **system**, not simply adding an API call to an application.

```text
USER / BUSINESS PROBLEM
          │
          ▼
      RESEARCH
          │
          ▼
     ARCHITECTURE
          │
    ┌─────┴─────┐
    ▼           ▼
  RULES        AI
    │           │
    │      ┌────┴─────┐
    │      │ LLM / CV │
    │      │ RAG / ML │
    │      └────┬─────┘
    └──────┬────┘
           ▼
      APPLICATION
           │
           ▼
        TESTING
           │
           ▼
      DEPLOYMENT
```

**data → retrieval → model → validation → business logic → API → UI → monitoring → deployment**
